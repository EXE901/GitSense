================================================================
GitSense — Shell-Level Responsive Fix Report
================================================================

This pass addresses the REAL root cause identified in the prior
Visual Mobile QA report: the AppShell grid was hard-coded to
reserve a 240 px sidebar track on every viewport, even when the
sidebar element itself was correctly hidden below `lg:`.

Result of the broken shell (BEFORE this pass):

  At 320 px viewport: main column = 240 px, ghost = 80 px
  At 390 px viewport: main column = 240 px, ghost = 150 px
  At 412 px viewport: main column = 240 px, ghost = 172 px
  At 768 px viewport: main column = 240 px, ghost = 513 px
                                              ^^^^^^
                              iPad portrait — CATASTROPHIC

Every prior compaction pass (briefing card, health panel,
metrics, insights, etc.) was correctly tightened — but the
container itself was broken. With a single shell-level fix
plus a mobile rebalance pass, the dashboard now uses the
full viewport on every phone and tablet, and the previously
"too-tight" copy now has the space to breathe.

================================================================
ROOT-CAUSE FIX (SHELL)
================================================================
File:  frontend/src/components/layout/app-shell.tsx

Before:
  <div
    className="grid min-h-screen"
    style={{
      gridTemplateColumns: 'var(--gs-sidebar-w) 1fr',
      transition: 'grid-template-columns var(--dur-base) var(--ease-standard)',
    }}
  >

After:
  <div
    className="grid min-h-screen
               grid-cols-[1fr]
               lg:[grid-template-columns:var(--gs-sidebar-w)_1fr]"
    style={{
      transition: 'grid-template-columns var(--dur-base) var(--ease-standard)',
    }}
  >

i.e.:
  - Below lg: single grid track at 1fr — main owns the
    whole viewport. The aside is hidden AND no longer
    reserves a track.
  - At lg+: keeps the existing two-column layout driven
    by the same CSS variable, so desktop layout is
    preserved exactly.

Inline `gridTemplateColumns` was removed so it can be
overridden by the responsive utility class.
